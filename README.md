# K-방산 ATLAS MVP

공개자료를 바탕으로 K-방산을 탐색하는 HTML5 전시 웹 시연입니다. Three.js, Vite, HTML·CSS·JavaScript로 구현했습니다.

## 실행

Node.js 22 이상과 Chrome을 권장합니다.

```sh
npm ci
npm run build
npm run preview
```

http://127.0.0.1:4173 에 접속합니다. 개발은 `npm run dev`입니다. 외부 기기에서 접속하려면 운영 환경에서 호스트·방화벽을 별도로 설정해야 합니다.

## 시연 흐름

1. 한반도 3D에서 체계를 선택하고 공개 근거와 사업 설명을 확인합니다.
2. 지상·해상·공중·우주 또는 군별 필터와 검색으로 탐색합니다.
3. 세계 수출에서 공개된 폴란드 계약 사례를 확인합니다.
4. 지식 관계망에서 체계·제작사·사업·국가·출처 연결을 탐색합니다.
5. 화면 설정에서 자동·가로·세로, 좌측·하단 메뉴, 전시 크기를 전환합니다.

전체 화면, 시점 복원, 확대·축소, 마우스 회전, 터치 조작, 선택 링크 공유, 처음으로 복귀를 제공합니다. 작은 화면과 세로 화면에서는 콘텐츠 영역을 스크롤합니다. 메뉴와 검색은 동일한 상태를 공유합니다.

## 데이터 범위

현재 수록 체계 9개, 공개 근거 12개, 수출 사례 국가 1개(폴란드)입니다. 전국 사업·전체 수출 통계가 아닙니다. 계약·납품·개발 사건을 구분하고 날짜와 원문 링크를 제공합니다. 공개자료 추가 및 검수 없이 총액·전체 순위로 확대 해석하지 않습니다.

지도는 Natural Earth 해안선을 단순화한 입체 전시 모형입니다. 실제 고도 지형, 작전 배치, 공장 위치, 위성 궤도가 아닙니다. 모델도 체계를 설명하는 도형입니다. 지도 출처·처리는 `public/data/provenance.json`과 `scripts/prepare-geo.mjs`에 있습니다.

관계망은 설명용 데이터 모델이며 정식 OWL 추론 엔진은 아닙니다. 사이버·전자 데이터 확장, AI 인수인계 도우미, 다국어, 전체 통계 수집은 후속 범위입니다.

## 검증

미리보기 서버와 설치된 Chrome이 필요합니다.

```sh
npm run qa:browser
npm run qa:accessibility
npm run qa:touch
```

`docs/evidence`에 실제 Chrome 화면과 검사 결과를 저장합니다. 터치는 에뮬레이션 검증이며 실제 키오스크 장비 인증은 아닙니다. WebGL 중단은 제어된 이벤트로 재현했습니다. 상세 결과와 남은 제약은 `docs/QA.md`를 확인하세요.

한글 폰트는 현재 문구의 서브셋입니다. 문구를 크게 추가할 때 폰트 서브셋을 다시 생성하거나 `@fontsource/noto-sans-kr`의 전체 한국어 폰트를 사용하세요. 폰트 라이선스는 `src/assets/LICENSE`에 보관했습니다.

기획은 `docs/PRD-MVP-v0.1.md`, 시각 규칙은 `DESIGN.md`입니다.

## 밝은 전시 화면 개편

첫 화면에서 육군·해군·공군·해병대 또는 지상·해상·공중·우주를 큰 카드로 선택할 수 있습니다. 대표 체계를 바로 눌러 상세로 이동해도 됩니다. `처음으로`는 최초 선택 화면으로 돌아갑니다.

새 `변천 비교` 메뉴는 선택한 체계의 과거·현재·미래를 비교합니다. K2는 공식 연혁의 2007년 시제 출고→2010년 양산 계약과 수록된 2025년 계약을 연결했습니다. 초소형위성은 2025년 발표 당시 향후 계획을 표시합니다. 자료가 없는 과거나 미래는 미확인 상태입니다. 전 체계의 역사적 선행/후속 모델과 성능 비교를 완료한 데이터베이스는 아닙니다.

밝은 자체 테마는 Fluent 2와 Material 3의 표면·선택 역할, Palantir의 연결 정보 구조를 참고했습니다. 해당 회사의 공식 UI 라이브러리를 설치한 것은 아닙니다. 화면과 3D 장면의 색상을 역할 토큰으로 관리합니다.

개편 검증은 `npm run qa:redesign`, 폰트 문구 갱신은 `npm run fonts:subset`으로 실행합니다. 최종 캡처·검사 원본·독립 검토는 `docs/evidence/light-v2`에 있습니다.

## 관람객 전시 기능

홈에서 군별/환경별 탭을 선택하거나 음성 전시를 시작합니다. 음성 전시는 5개 체계의 큰 자막·3D 모형·참여기관을 보여주며, 이전/다음/다시 듣기/중지와 선택적 자동 넘김을 제공합니다. 설치된 한국어 음성이 필요하며 미지원 기기에서는 글로 안내합니다.

체계 상세에는 역할, 회전 모델, 기업·연구기관·사업기관과 공개 근거 링크가 있습니다. 지도 모형이나 라벨을 클릭해 선택하고, 사천·울산·창원·부산의 공개 산업 연결을 탐색할 수 있습니다. 전국 전체 사업장이나 실제 군 배치가 아닙니다. 제조사 CAD 수준 모델은 후속 제작 범위입니다.

해외 사례와 적용 방식은 [전시 조사](docs/EXHIBITION-RESEARCH.md), 새 검증은 docs/evidence/exhibition-v3를 확인하세요. `npm run qa:exhibition`, `npm run qa:voice`로 추가 검사합니다.

## 객체 중심 3D 체계 시연 (v4 당시 기록, 현재 동작은 v6·v7 참조)

지도 위 체계 모형/라벨을 클릭하면 해당 체계 시연이 열립니다. 홈·목록에서 고른 체계는 상세의 ‘3D 체계 시연’으로 진입합니다. 외형 회전, 설명용 외형 구성 펼치기, 6초의 역할 표현과 재생·중지·초기화를 제공합니다. 연관 체계의 연결 이유와 공개 근거를 확인하고 다음 시연으로 이동할 수 있습니다.

46개 객체·53개 타입 관계를 구성한 로컬 온톨로지 모델입니다. 팔란티어 객체·관계 개념을 참고했으며 Foundry/AIP를 설치한 것은 아닙니다. 공통 환경/참여기업 관계는 실제 무기 간 운용 연동을 뜻하지 않습니다. 설명용 모형·단순 역할 표현이며 실물 내부 구조나 성능 시뮬레이션이 아닙니다.

`npm run qa:ontology`로 새 동작을 검사합니다. 설계·범위는 docs/ONTOLOGY-DEMO.md, 새 캡처·검사·독립 검토는 docs/evidence/ontology-v4에 있습니다.

실물 외형 전시 v5: [자료 유형·저작권·제약](docs/REALISTIC-EQUIPMENT.md). 공개 3D 2개·실물 사진 2개·준비 상태 5개로 구분합니다. 외부 장비 뷰어·사진은 인터넷이 필요합니다. 최종 제조사 승인 3D 전시 납품은 아직 아닙니다.

한반도 운용 환경 v6: [환경 시연·지형 자료·제약](docs/ENVIRONMENT-DEMO.md). 고도 기반 한반도 지형과 지상/수면/수중/공중/연안/우주 환경을 연결합니다. 현재 수록 10개 체계, 공개 3D 2개·실물 사진 3개·자료 준비 중 5개. 환경 시연은 이름이 붙은 설명용 마커이며 실물 장비 GLB를 지형 안에 통합한 동작 시뮬레이션은 아직 아닙니다.


## v7 스크롤 전시 홈

홈 → 한반도 3D → 세계 계약 사례 → 체계 선택의 네 장면으로 구성합니다. 실제 FA-50 사진과 실시간 3D 지도를 중심에 두고, 기업·사업·출처 상세는 펼쳐서 확인합니다. 부드러운 native 스크롤, 장면 공개, 페이지 전환, 모션 감소를 지원합니다. 홈 메뉴는 기본 숨김이며 전시 재생 중 부가 패널을 접고 종료 시 복원합니다. 2400px 이상 대형 가로 화면은 별도 확대 배치를 사용합니다.

`npm run dev` 또는 `npm run build` 후 `npm run preview -- --host 127.0.0.1 --port 4173`으로 확인합니다. [검증·남은 제약](docs/evidence/story-v7/QA.md). 세계 데이터는 현재 폴란드 1개국 공개 계약 사례이며 전체 방산 시장 통계가 아닙니다. 실사 동영상과 모든 장비의 승인된 고정밀 3D 자산은 추가 확보가 필요합니다.

## 실제 지형·탑승 관측 시연

홈의 **실제 지형·탑승 시연** 버튼 또는 `?experience=terrain`으로 진입합니다. 평창 일대의 위성·항공 영상과 실제 고도 지형 위에서 T-80U 공개 모델을 외부·해치·조종수 관측 시점으로 살펴볼 수 있습니다. 실내 재현은 포함하지 않으며 인터넷 연결이 필요합니다. [시연 구성과 자료 출처](docs/TERRAIN-EXPERIENCE.md)를 참고하세요.

## 통합 위성 전시

메인 지도는 실제 Esri 영상과 ArcGIS Terrain3D 고도를 사용합니다. 23개 대표 체계와 공개 근거가 있는 6개국 수출 사례를 제공합니다. KAAV·FA-50·도산안창호급·누리호는 공개 자료 기반의 독자 GLB 외형을 지형 위에서 관찰할 수 있습니다. 제조사 CAD·검증된 내부·성능 시뮬레이션은 아닙니다. 상세 범위는 `docs/EXHIBITION-INTEGRATION.md`, 출처는 각 모델의 ATTRIBUTION 문서에 있습니다.
