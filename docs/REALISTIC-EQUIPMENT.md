# 실물 외형 전시 v5

단순 도형 장비와 임의 이동 애니메이션을 제거했습니다. 지도는 해안선 입체 지도와 중립 선택 마커를 사용하며 장비 선택 시 외형 자료와 기존 사업·기관·관계 정보를 연결합니다.

| 체계 | 자료 | 저작자 / 사용권 | 상태 |
|---|---|---|---|
| K9 | 텍스처 공개 3D | Muhamad Mirza Arrafi / CC BY 4.0 | 온라인 외부 뷰어 |
| K2 | 상세 외형 공개 3D | jjj0605 / CC BY 4.0 | 금속 표현, 실제 도색과 다름 |
| FA-50 | 실제 사진 | ROKAF / CC BY 2.0 | 3D 아님 |
| 천무 | 실제 사진 | 대한민국 국방부 / 공공누리 제1유형 | 3D 아님 |
| 기타 5개 | 미확보 | 정확한 자산·전시 권리 확인 필요 | 임의 모델 대체 없음 |

출처 URL과 저작권은 src/equipment-assets.js에 있으며 화면에서도 원본과 저작자 표시를 제공합니다. 사진과 모델은 현재 배치나 운용 상태를 입증하지 않습니다. 현재 현황은 기존 수록 공식 발표의 날짜와 근거로 판단해야 합니다. 공개 3D는 제조사 승인 실측 CAD가 아닙니다.

외부 뷰어와 사진은 인터넷을 필요로 합니다. 오프라인 납품 및 모든 장비의 실물 수준 3D·동작 시연을 위해 제조사 승인 glTF/GLB 또는 사용권을 확보한 제작 자산이 필요합니다. 유료 자산 구매나 제조사 자료 확보는 수행하지 않았습니다. K9·K2 공개 모델에는 검증된 애니메이션이 없으므로 역할 안내만 제공하며 임의로 동작을 재현하지 않습니다.

## 검증
최종 빌드 후 9개 장비 × 가로 PC / 세로 전시 / 모바일 27개 화면을 확인했습니다. 공개 3D 6개 화면은 viewerready 확인, 사진 6개 화면은 실제 이미지 로딩 확인, 15개 준비 화면은 정직한 대안 설명을 제공합니다. 재설정·역할 안내·연관 체계·Escape 복귀를 실제 Chrome에서 확인했습니다. DOM 가로 넘침과 앱 런타임 오류는 없습니다. 외부 Sketchfab 프레임 내부에서 axe ARIA 위반 2개를 발견했으며 원본 결과를 보존했습니다. 호스트 자체 노드에서는 위반을 발견하지 않았지만 전체 접근성 통과라고 주장하지 않습니다. 실제 키오스크 하드웨어·장시간 운용·인터넷 단절 시연은 검증하지 않았습니다.
