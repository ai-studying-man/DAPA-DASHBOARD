# 실사 외형·실제 위성 지형 구현 기록

> 후속 사용자 지시에 따라 아래 SAM/Higgsfield 기반 모델은 기본 체험에서 제외했다. 현재 K9·K21·K216·천무는 GPT ImageGen 참고 재질 + Blender 부품 외형 GLB, FA-50은 Blender 표면 보완본을 사용한다. 이전 작업 기록을 현재 구현으로 혼동하지 않는다. 최신 제작 기록: `public/models/GPT-BLENDER.md`. 현재 결과도 전체 실사화 완성본은 아니다.

## 이번 변경

관람객의 `둘러보기`와 `3D 시뮬레이션`은 `visitor-satellite-stage.js`를 통해 Cesium + Esri World Imagery + ArcGIS Terrain3D를 사용한다. 기존 창작 언덕 장면을 기본 체험에서 사용하지 않는다. 장비별 지상·해상·공중·우주 전시 위치를 분리하고, 누리호는 나로우주센터 제2발사대 일대로 이동했다. 실제 군 배치나 운용 항로라는 의미가 아니다. 위성 사진의 해상도 한계와 건물·나무·파도의 입체 미재현은 남아 있다.

기존 무기체계 목록, 세 가지 핵심 탭, 제조사 연결, 고급 모델 검토 화면을 유지한다. 장비 선택으로 바로 관람하고 이전/다음 장비로 넘길 수 있다. 범용 장난감 수준의 미검증 MVP를 기본 지도에서 실제 장비처럼 표시하지 않으며 기존 검토 화면에 보존한다.

| 체계 | 실제 반영 상태 | 남은 문제 |
|---|---|---|
| K9 | 실제 사진→SAM 3 3D→Blender UV 보존·미터 정규화→GLB | 한 장 복원의 뭉개짐, 숨은 면 추정, 1K 색상 텍스처 |
| K21 | K21 실사 사진 기반 별도 복원 GLB | 작은 부품과 궤도 연결부 정밀도 미달 |
| K216 | DVIDS 실제 K216 사진 기반 별도 복원 GLB | 후면·차체 비례 추정과 거울 주변 아티팩트 |
| FA-50 | 실사 사진 기반 별도 복원 GLB | 조종석·흡입구·패널 선의 정밀도 미달 |
| 도산안창호급 | CC0 제작자 모델, 실제 UV와 2K PBR 재질, 정적 외형만 변환 | 제조사 실측 검증 아님, 전시용 수면 높이 추정 |
| K2 | 기존 모델 유지; 사진 복원 후보는 검수 탈락 | 후보의 위장망 주변 형상 왜곡으로 기본 적용하지 않음 |
| 충남함 | FFG-828 전용 Blender 선체·상부구조 초안 | 실사 수준 미달, 정밀 외형·재질 자산 미확보 |
| 천무 | 8륜 전용 차체·외장 부품 초안과 사진 패치 | 사진→3D 작업 실패, 실사 수준 미달 |
| 나머지 체계 | 기존 목록·검토 자산 유지 | 정밀 실사 외형 제작 완료 아님 |

**전체 실사화 완성으로 평가할 수 없다.** AI 이미지의 사실적인 인상과 검증된 3D 정밀도를 혼동하지 않는다. 한 장 사진 기반 복원은 360도 실측 형상·재질을 제공하지 않는다. 4K/8K PBR 또는 실제 부품 형상 보강은 별도 제작·검수가 필요하다.

## 재현과 출처

- Blender 4.5.9. 사진 복원: `scripts/blender/import_photo_reconstruction.py`; 원본 GLB는 로컬 `.local/asset-research/`, 원본 사진 및 라이선스는 `public/models/DETAILED-ASSETS.md`에 기록.
- 네이티브 `.blend`, 비교 렌더, 삼각형·텍스처·치수 보고서: `artifacts/3d/photo-reconstructed/`.
- 도산안창호급 변환: `scripts/blender/import_kss3.py`, 결과와 출처 보고서 `artifacts/3d/verified-assets/`.
- K21/K216 및 충남함/천무 수작업 검토 초안: `scripts/blender/build_referenced_exteriors.py`와 연결 모듈. K21/K216의 기본 관람 GLB는 사진 복원본으로 연결한다.
- 기존 고급 지형 관찰의 K9/K21/K216도 상세 자산 레지스트리를 참조한다. 사진 복원 모델에서는 검증되지 않은 조종수/해치 위치를 제공하지 않는다.

## 브라우저 검수

`npm run build`, `node scripts/qa/satellite-equipment.cjs`, `node scripts/qa/satellite-recovery.cjs`.

실제 Chrome에서 1440×1000과 390×844, K2·K9·K21·K216·FA-50·도산안창호급·충남함·천무·누리호를 관찰한다. 위성 타일과 고도 제공자, 실제 GLB 경로, 넘침, 시점·이동·초기화, 고정 체계 이동 금지, 그래픽 연결 손실과 GLB 실패의 재시도를 확인한다. 최신 결과는 `artifacts/satellite-equipment/report.json`, `recovery.json`과 화면 캡처를 기준으로 판단한다. 이전 Three.js 기반 QA의 통과 기록을 현재 Cesium 검증으로 재사용하지 않는다.

검수 중 발견한 누리호 상하 잘림은 세로/가로 실제 화각 중 좁은 화각에 맞춘 바운딩 구 fit으로 수정했다. 모델 준비 타임아웃, 비동기 중 화면 이탈, 컨텍스트 손실·오프라인 상태 안내와 조작 중단을 추가했다.
