# v2 배포 결과 비교 · 진행 중

대상: https://cookiesh1.github.io/dapa-dashboard-v2/

실제 REA `capture_browser_scenario`로 Chrome 임시 프로필에서 초기 페이지를 열고 DOM·접근성 트리를 수집했다. Evidence: `ev_ae3f6dc9d21abe4a8c5c4ac2c8cb31300c3449730f8a43e3563299d5491ff94c`.

관찰: 초기 배포 DOM에 군별 대표 체계, 방사청 4가지 역할, 12개국 수출 사례 표시, 23개 체계·37개 공개 근거, 출처가 붙은 실제 장비 사진과 위성/고도 자료 안내가 있다. 초기 화면 관찰일 뿐 각 지도 성공이나 실제 3D 품질·전체 상호작용 성공을 입증하지 않는다. 원 저장소 전체를 읽거나 복제한 것으로 표현하지 않는다.

우리 프로젝트 보완 우선순위: 단순 구형 언덕·평면 바다와 저해상도 인물은 제거 또는 보조로 제한하고, 장비 관찰을 중심으로 지형·해안의 연속성, 재질별 반사 특성, 실제 사진과 형상의 정합을 개선한다. 수출 국가 수를 맞추기보다 개별 공개 근거를 검증해야 한다. 배포 DOM의 수치는 검증된 전체 수출 통계가 아니다.

K2 형상/재질 및 환경 개선 작업은 별도 후보 자산으로 진행 중이며, 결과 렌더와 실사 품질 한계를 확인하기 전 기본 장비로 승격하지 않는다.

## 정적 분석 추가
공개 GitHub 저장소의 루트 목록은 assets/cesium/data/lighting/media/models/index.html을 담은 배포 형태임을 브라우저에서 확인했다. 전체 원본 개발 저장소가 공개돼 있다고 추정하지 않았다. 배포 DOM에서 관찰한 `assets/index-CD9CYJld.js`만 분석 목적으로 내려받았다(389,753 bytes). REA `analyze_javascript_application` summary: 부모 Evidence `ev_92105059d24cabef8dc19ba5d9fbf963aa38619d99571ac7c9021fce4c412034`, 요약 `ev_6c4cfaf03ce6dc31e4049f81172a5bb629c484d34fd88a2de01bbb6cce3c2da1`. 1개 JS 파싱 성공, AST 37,460개 방문. 의미 그래프는 partial이며 unknown 4,794개가 남는다. 이 숫자는 기능 오류 개수가 아니다. 나머지 배포 청크와 지도·모델 자산은 정적 분석 범위 밖이다. 원본 코드를 복원했다고 주장하지 않는다.

보존 증거: artifacts/rea-v2-static-summary.json, artifacts/rea-v2-accessibility.txt. 외부 JS는 분석용 .local 폴더에만 두었고 제품 코드나 모델로 복사하지 않았다.

## 이번 적용과 미완료
- 별도 `?view=service&surface=refined` 외형 관찰 후보: 단순 인물·주행 제어 숨김, K2 재질 역할/모서리/차륜 입체 디테일 보정. 원본 기본 모델 유지.
- 구형 언덕을 연속 높이 메시와 해안·수면·원거리 수목으로 교체. 중앙 이동 구역 제한으로 보행 지면 불일치를 줄임.
- 실제 위성/고도 지형은 기존 지도 경로를 별도 연결. 새 서비스 지형은 실제 한반도 DEM이 아니며 실측 지형 복원 완료가 아니다.
- 핵심 미완료: K2 차체·포탑 실루엣의 정밀 재구축, 실사 재질, 실제 DEM 기반 연안 장면, 인물 실사화. 검증된 사진 정합 없이 실사화 완료로 표시하지 않는다.

## 최종 검증과 상태
`npm run build`, `node scripts/audit-service-surface.mjs` 통과. 검사값: K2 후보 6,751,700 bytes, 165 meshes, 5 materials, 필수 부품 그룹 유지. 육군·공군 중앙 관람 구역 및 해병대 x±14/z0~14의 지면 높이를 검사했다. 동행 대상도 같은 범위로 제한한다. 정적 관찰 모드의 대원 이동 입력은 차단한다.

실제 브라우저 4개 군별 장면과 375×812 모바일 캡처: artifacts/realism-web/. 처음 모바일 캡처는 다른 탭에 viewport가 적용돼 무효였고, 전용 모바일 탭에서 innerWidth/innerHeight 확인 후 교체했다. 두 독립 검토는 후보 UI·코드 통합 PASS, 사용자가 요구한 정밀 실사화는 미완료라고 판단했다. 이 기록은 실사 품질 완료 판정이 아니다.
