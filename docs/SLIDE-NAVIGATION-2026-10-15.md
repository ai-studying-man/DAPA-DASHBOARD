# 모바일 슬라이드 전환

- 모바일 중심: 처음 → 관람 안내 → 대표 시연 → 한반도 → 세계 → 장비 찾기, 총 6개 페이지.
- 각 슬라이드는 현재 표시 영역과 같은 크기. 안내 화면부터 상단 64px, 중앙 가변 콘텐츠, 하단 80px의 공통 구조를 사용한다.
- 처음에는 다음 페이지 이동·언어 선택이 화면 안에 들어간다. 이후에는 이전·페이지 선택·다음이 하단에 고정된다.
- 모바일/태블릿은 native smooth vertical scroll + mandatory snap. 페이지를 넘긴 후 화면 한 장에 맞춰 정렬한다. 긴 콘텐츠는 중앙 영역에서 별도로 스크롤된다.
- 1000px 이상 PC 또는 `?presentation=kiosk`에서는 같은 페이지를 좌우 전환한다. 책장 효과는 도입하지 않았으며 현재는 가독성을 유지하는 native 이동을 사용한다.
- 모션 감소 설정에서는 버튼 이동을 즉시 적용한다. 버튼 이동 완료 시 제목으로 초점 이동, 현재 페이지 외 슬라이드는 inert 처리한다.
- 실제 브라우저 375×812, 768×1024, 1280×900에서 전체 페이지, 375×667 영어 홈을 기록했다. 실제 터치 기기와 키오스크 장시간 사용은 미검증이다.
- 전군 현황/실사 영상/3D/출처 기능은 기존 경로에 연결한다. 지도 준비 상태는 외부 서비스 조건에 따라 달라질 수 있다.
- 이번 작업은 로컬 변경이다. GitHub 공개 배포는 아직 실행하지 않았다.
