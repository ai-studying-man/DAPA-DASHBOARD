# 국내외 방산 전시·시연 사례와 보완 우선순위

조사일: 2026-10-12. 분석 대상 대시보드 구현 커밋: a1348b2. 기존 구현은 원격 main과 일치하고 Pages 배포 성공을 확인했다.

제조사·연구기관의 공식 발표와 해당 작업을 수행한 제작사의 공개 사례를 사용했다. 제작사 사례는 고객의 독립 인증과 구분한다. 아래는 공개 자료의 전시 구성에 관한 조사이며 성능 검증 보고서가 아니다. 각 기업의 비공개 CAD 입수 경로, 엔진 소스, 제작비와 개발 기간은 확인하지 않았다.

## 2. 해외 사례

### Saab — Gripen E 전시용 조종석 시뮬레이터

2018년 인도 Defexpo에서 WAD(대형 조종석 화면)를 갖춘 Gripen E 시뮬레이터를 처음 전시한다고 공식 발표했다. 제품 화면과 입력 인터페이스를 방문객이 경험하게 하는 사례다. 과거 전시 기록이며 2026년 최신 부스 구성으로 일반화하지 않는다.

- 작업: 조종석 화면·입력 인터페이스·시뮬레이터를 연결한 체험 전시.
- 적용: 검증된 좌석 위치와 공개 계기 배치가 확보된 뒤 탑승 시점과 설명 UI를 연결.
- [Saab 공식 발표, 2018-04-12](https://www.saab.com/newsroom/press-releases/2018/saab-presents-gripen-e-simulator-with-wide-area-display)

### Rheinmetall·Varjo — 이동형 XR 훈련 체험

2025년 I/ITSEC 관련 발표에서 Rheinmetall의 모듈형 지상 훈련 시스템에 Varjo XR-4를 결합하는 협력을 설명했다. 실제 조작 하드웨어와 가상 지형을 함께 사용하고, 차량에 따라 조종석 인서트를 바꾸는 방식이다. XR 통합 협력의 발표를 전체 사업 완료나 훈련 효과 인증으로 표현하지 않는다.

- 작업: 이동 가능한 조작 장비, 교체형 조종석, 헤드셋, 가상 지형의 통합.
- 적용: 실제 좌석·조작계를 사용하는 현장 전시를 별도 실행 환경으로 설계.
- [Rheinmetall 공식 발표 PDF, 2025-11-25](https://www.rheinmetall.com/Rheinmetall%20Group/Presse/News/Documents/2025/11/2025-11-25-rheinmetall-varjo-partnership-for-xr-simulation.pdf)

### Naval Group — Naval XPlore

DEFEA 2023 공식 발표에서 개인화 가능한 몰입형 3D 전시 공간을 설명한다. 제품·서비스와 함정의 활동 환경을 연결하는 고객 설명 방식이다. 공식 쇼룸 연재에서는 마케팅·영업·프로그램·혁신 담당자가 함께 기획하고, 관람객과 발표 내용에 맞추는 작업을 설명한다.

- 작업: 대상 관람객에 맞춘 이야기, 모듈형 전시 공간, 제품·서비스 연결, 여러 담당 조직의 공동 검토.
- 적용: 일반 관람·기업 상담·해외 방문단용 설명 깊이와 언어를 각각 준비.
- [Naval Group DEFEA 2023 공식 발표](https://www.naval-group.com/en/presse/naval-group-participates-defea-greece)
- [공식 쇼룸 연재의 검색 확인 자료](https://www.naval-group.com/en/thematique/defense-naval/systems?page=1): 이번 직접 원문 요청은 실패했고, 연재 본문은 검색 결과에서 확인했다.

### L3Harris·Inhance — 고객 브리핑 센터

제작사 Inhance는 L3Harris Global Innovation Center에 관람 동선, 몰입형 기술, 인터랙티브 콘텐츠, 인터랙티브 벽과 시뮬레이션 영상을 제작했다고 설명한다. Inhance의 일반 EBC 제작 과정에는 이야기 기획, 실시간 3D·모션 그래픽·앱, 디스플레이와 음향 통합, 콘텐츠 갱신이 포함된다. 이 일반 역량 모두를 L3Harris 프로젝트에 실제 설치했다고 단정하지 않는다.

- 작업: 콘텐츠와 공간·화면·방문 동선을 함께 설계하는 전문 전시 제작.
- 적용: 발표자 제어 화면, 설명 화면과 장비 화면의 동기화, 콘텐츠 버전 관리.
- [제작사 Inhance 공개 사례](https://www.inhance.com/capabilities/ebc): 검색에 수록된 본문 확인. 직접 웹 추출 결과는 비어 있었다.

## 3. 제작 업무를 어떻게 나눌 것인가

다음 단계는 위 사례에서 얻은 우리 프로젝트용 제안이다. 모든 기업이 동일한 제작 절차나 특정 엔진을 쓴다는 주장은 아니다.

1. **자료와 형상 검수**: 제조사 전시 담당자에게 공개 전시용 외형 GLB, 재질 참고 사진, 장비 형식·개량형, 공개 가능한 내부 파노라마, 검증된 좌석 위치를 요청한다. 정확한 내부가 제공되지 않으면 외형 범위로 제한한다.
2. **실시간 자산 제작**: 단위·축·지면 기준을 통일하고, 메시 경량화·LOD·재질·텍스처·부위 구분을 준비한다. 브라우저용과 현장 XR용 산출물을 구분한다. 원본 제공과 공개 웹 재배포 권한은 각각 확인한다.
3. **지형과 장비 정합**: 좌표뿐 아니라 받침 높이, 방향, 해수면, 발사대·활주로 등 실제 주변 시설을 맞춘다. 사진의 지도 텍스처만으로 근접 환경이 완성됐다고 판단하지 않는다.
4. **관람 시나리오**: 외형 → 활동 환경 → 관측 시점 → 공개 구성 → 기업·수출 근거로 장면을 연결한다. 장면별 설명·카메라·자막·핫스폿을 같은 데이터로 관리한다.
5. **전시 운영**: 터치 PC, 대형 화면, 발표자 제어, 이어보기·초기화, 오프라인 자산과 장애 대안을 준비한다. VR·실제 좌석을 쓰는 경우 별도의 현장 실행과 조작계 통합을 검토한다.
6. **공동 승인과 업데이트**: 형상과 문구는 제조사/전문가 검수, 번역은 별도 검토, 현장은 설치 장비에서 확인한다. 제품 개량과 수출 발표가 바뀌면 관련 자료를 함께 갱신한다.

| P1 — 현장 운영 | GitHub Pages와 외부 영상·고도 서비스 사용. | 허용된 로컬 자산 패키지, 데이터 연결 실패 대안, 발표자 제어, 자동 초기화 | 현장 네트워크 단절·장시간 운영·실제 화면 장비에서 관람 지속 |
| P2 — XR·실제 좌석 | 웹상의 추정 관측 시점 제공. | 검증된 내부와 실제 조작계를 쓰는 별도 현장 체험 | 공급받은 모델·좌석·조작계의 일치와 현장 체험 검수 |

추천 첫 목표: 제조사 검수가 가능한 대표 장비 한 대의 외형·주변 환경·검증된 관측 시점·짧은 설명 투어를 완성한다. 동시에 23개 체계는 공개 자료 탐색의 폭을 유지한다. 위 우선순위는 제안이며 이번 조사에서 추가 구현했다고 표시하지 않는다.
