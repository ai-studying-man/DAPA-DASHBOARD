2. 포탑·포신 그룹이 없는 모델의 부품 동작, 분리, 부품 선택을 비활성화했다. 기존 모델에 존재하지 않는 가동 부품은 만들지 않았다.
3. K2/K9 예시 동작 중 각도 표시에 들어 있던 잘못된 인코딩 바이트를 UTF-8 `°`로 수정했다.
4. KAAV의 이미 존재하는 모델 출처 파일과 라이선스를 자산 설정에 연결했다. 공개 참고자료가 제조사 페이지가 아닐 수 있어 비교 링크 라벨을 '공개 제작 근거'로 바꿨다.
5. `npm run qa:models`로 23개 체계의 로컬 자산, 사진, 모델 출처, 기본 GLB 헤더, 가동 그룹 및 재질·텍스처 참조를 검사한다. `docs/MODEL-ASSET-STATUS.json`에 6개 초안과 로컬 모델이 없는 17개 체계를 구분해 기록한다. 이 검사는 전체 glTF 표준 검사나 텍스처 픽셀/실사 품질 판정이 아니다.
6. 화면 검증을 재실행할 수 있도록 `npm run qa:local-models`를 추가했다. Vite 개발 서버와 Playwright Chromium이 필요하다. `QA_URL`, `CHROME_PATH`로 실행 환경을 지정할 수 있다.
