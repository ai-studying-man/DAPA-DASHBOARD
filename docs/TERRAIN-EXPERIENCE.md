# 실제 지형 장비 관람 시연

작업 순서: 데이터·모델 사용권 확인 → 위성·고도 지도와 장비 배치 → 외부·탑승 관측 시점 → 브라우저 관람 확인.

진입 주소: `?experience=terrain`. 홈의 실제 지형 시연 버튼으로도 진입합니다.

CesiumJS로 Esri World Imagery 위성·항공 영상과 ArcGIS Terrain3D 고도를 스트리밍합니다. 지형 높이 배율은 1입니다. 자료의 지역별 해상도와 촬영 시점은 서로 다르며 실시간 영상이 아닙니다. 공개 서비스 이용에는 인터넷 연결이 필요합니다. 이미지 대량 다운로드 및 오프라인 재배포는 포함하지 않습니다.

첫 장비는 javanilga의 Tank T-80U 공개 모델입니다. K2/K9 또는 한국군 도색으로 소개하지 않습니다. 제조사 CAD와 검증된 실내 자산이 아니며 해치 관측·조종수 관측 위치는 외형 기반의 추정치입니다. 조종수 시점은 실내 재현 없이 전방 관측을 제공합니다. 장비는 정지해 있고 실제 배치·성능·전투 시뮬레이션을 의미하지 않습니다.

장비 자산 출처·사용권·변환 내용은 `public/models/ATTRIBUTION.md`에 기록합니다. 시연 장소는 강원 대관령 일대의 전시용 좌표입니다.

## 구현 및 확인

위성·고도 지도, 로컬 T-80U 모델, 외부·해치·조종수·지역·한반도 시점, 드래그·방향키·화살표 조작, 안내 시작·중지, 처음 시점, 전체 화면과 홈 진입 링크를 구현했습니다. 지형 상세도 변화에 따라 렌더링된 지면 높이를 다시 계산해 장비와 카메라를 보정합니다.

관측 범위는 외형 기반 위치에서의 주변 시야입니다. 실내 좌석·계기판·장비 동작·물리 주행은 제공하지 않습니다. 지형의 정확도와 영상의 선명도는 공급 데이터의 해상도에 제한됩니다.

2026-10-12 확인: 생산 빌드 성공, JavaScript 구문·diff 공백 검사 통과. Codex 브라우저에서 배포 빌드의 외부·해치·조종수·주변·한반도 시점, 화살표 조작, 안내 완료와 수동 시점 복귀, 홈 진입을 확인했습니다. 390×844 모바일 뷰포트에서 문서 가로 너비 375px로 넘침이 없었습니다. 최종 생산 빌드 관람 중 수집된 브라우저 오류는 없었습니다. 화면 기록은 Git에서 제외된 docs/evidence/terrain-demo에 보관합니다. 기존 Three.js 청크의 500kB 경고는 남아 있습니다. 실제 키오스크·VR 헤드셋·장시간 운용은 확인하지 않았습니다.

GitHub Pages와 같은 /DAPA-DASHBOARD/ 하위 경로에서도 생산 빌드의 엔진·모델이 HTTP 200으로 응답하고 해치 시점까지 진입하는 것을 확인했습니다. 변경 사항은 로컬 작업 폴더에 있으며 GitHub에 푸시하거나 공개 배포하지 않았습니다.
