# 군별 대표 실사 시연

육군 K2, 해군 도산안창호급, 공군 FA-50, 해병대 KAAV를 먼저 구현했다. 공개 열람·사용 조건이 확인된 범위에서 자료를 확보했으며 모든 세계 무기체계 자료나 제조사 CAD를 확보했다는 뜻은 아니다.

## 확보한 자료와 전시

| 체계 | 주 영상 | 제공 방식 | 3D 관람 범위 |
|---|---|---|---|
| K2 | 2016 계룡 전시 자세 제어 실사, 1080p/72초 | CC BY 3.0 원본 로컬 WebM | 공개 외부 Sketchfab, 제조사 CAD 아님 |
| 도산안창호급 | 해군 공식 태평양 항해 영상 | 정책브리핑 원문 플레이어, 자체 자막 유지 | 공개 사진 기반 외형 재구성 |
| FA-50 | Cope Thunder 26-1 FA-50PH 실제 비행, 1080p | DVIDS Public Domain 표시 영상 스트림 | 공개 치수·사진 기반 외형 재구성 |
| KAAV | 하와이의 대한민국 해병대 KAAV-7A1, 4K | DVIDS Public Domain 표시 영상 스트림 | 공개 사진 기반 외형 재구성 |

영상의 촬영 환경과 3D의 한반도 전시 좌표는 별개다. FA-50 영상은 필리핀 운용 수출형이다. 공개 방문·훈련 사례를 수출 계약으로 바꾸어 집계하지 않는다. 공식 원문·개인 촬영·실제 사진·외형 재구성·외부 뷰어의 종류와 기관/저작자를 표시한다.

## 데이터와 사용권

source-manifest.json: 4체계의 역할·제원·기업·사업·수출 원문 및 18개 고유 원문 주소의 확인 결과. local-asset-manifest.json: 신규 사진2개와 K2 영상1개의 공개 라이선스, 원본 메타데이터, 크기·SHA256. 공공누리와 CC 조건을 유지하며 정부·촬영기관의 보증이나 추천으로 표현하지 않는다. DVIDS 자료의 원문 저작권·표식·제3자 권리 조건도 함께 연결한다.

Navy 영상은 공개 플레이어를 연결하며 영상 파일을 추출·재배포하지 않았다. K2의 원본은 로컬이지만 나머지 영상 스트림·원문 플레이어와 위성 지도는 인터넷이 필요하다. 외부 제공 서비스 중단 시 사진·설명·원문·재시도 대안을 제공한다. 원음을 유지하고 해군 원문 플레이어가 제공하는 자막을 유지하며 새로운 발화 전사나 더빙을 생성했다는 주장은 하지 않는다.

## 사용 흐름

홈 대표 선택 → 실제 영상 → 같은 체계의 위성 지도·외형 관람 → 사업·기업·수출 근거. ?representative=k2 / dosan / fa50 / kaav 주소로 직접 진입·공유한다. 재생은 명시적 사용자 동작에만 시작한다. 체계 변경·닫기·화면 비활성에서는 중지한다. native 영상 종료·정지·오류에서는 설명을 복원한다.

## 재현

- npm run assets:representatives: 확인된 공개 파일 수집. 예기치 않은 라이선스 또는 80MiB 이상 파일은 거부한다.
- npm run verify:representatives: 원문 상태와 자료 확인 manifest 작성.
- QA_WIDTH=375 QA_HEIGHT=844 node scripts/qa/representatives.cjs: 실제 Chrome으로 시연·미디어·3D 이동·복귀 검증. QA_URL과 QA_EVIDENCE_DIR로 공개 사이트와 출력 위치를 지정한다.

제조사 실측 모델·검증된 내부·운용 성능 시뮬레이션·전시 하드웨어/스피커 품질·완전 오프라인 납품은 별도 확보와 현장 검증이 필요하다. 검사 보고서와 캡처는 Git에서 제외한 docs/evidence/representatives-v10에 보관한다.

## 브라우저 검증 범위

375×844, 768×1024, 1280×900, 1080×1920, 3840×2160에서 126개 상태 캡처와 4체계 실제 재생을 확인했다. 정지·닫기·주소 복원·3D 연결, 네트워크 실패/재시도, 종료·모션 감소·직접 링크를 검증했다. UI poster 상태의 axe 검사 4건은 위반 0건이며 전체 영상 접근성 인증은 아니다. Lighthouse 홈 6회 성능은 모바일 93/94/94, PC 93/95/92이고 접근성·권장사항·SEO는 각 100이다. 영상 재생·초점 전환 모션을 별도 기록했다. 링크 복사의 write 완료는 확인했으나 자동화 환경의 clipboard readback은 비어 있어 실제 붙여넣기는 검증하지 못했다.
