# Imagegen-first visual targets

Built-in image_gen generated two visual targets before further Blender work: `k2-coastal-target-v1.png` and matching clean `coastal-environment-target-v1.png`. Exact prompts: `prompts.json`.

K2 identity reference: `public/media/representatives/k2.jpg`, KBS VIEW–theDEEP / CC BY 3.0, https://commons.wikimedia.org/wiki/File:K2_Black_Panther_20161106.jpg . Images contain inferred equipment details and fictional Korean-inspired geography; neither is an actual photograph, manufacturer blueprint, DEM or verified photogrammetric reconstruction.

Blender matching sequence: set camera to scene reference; match large landforms and equipment silhouette; separate foreground gravel, rock, tree and sea meshes; author surface-specific UV/PBR maps; match overcast illumination, shadows and atmosphere; compare actual Blender renders against the target before adding motion. Use the clean environment plate as reference for independent background construction. Do not treat RGB brightness as calibrated elevation or label a background image plane as a fully reconstructed 3D environment. Equipment dimensions and unseen surfaces require independent reference verification. Existing dashboard models and UI have not been replaced with these images.
