# K2 정지 외관 재질·모서리 보완 후보

## 산출물
- `public/models/k2-surface-refinement.glb`: 6,751,700 bytes, 165 meshes, 98,224 triangles, material roles 5, image 1.
- `artifacts/3d/k2-surface-refinement/source.blend`: 수정 가능한 실제 Blender 원본.
- 같은 폴더 `before.png`, `after.png`: 동일 카메라·조명의 실제 Cycles 렌더.
- `scripts/blender/k2_surface_refinement.py`: 실제 실행한 재현 스크립트.

## 실제 변경
기존 사진 추정판의 가짜 패널·차륜 영상이 차체와 포탑 위로 늘어지는 문제를 제거한 비교 후보다. 실제 사진에서 관찰 가능한 올리브/모래/짙은색 계열을 참고해 반복 위장 패턴을 새로 작성하고, 장갑 도장·궤도 강재·차륜 고무·광학 유리의 재질 역할을 분리했다. 기존 분리된 삼각형 꼭짓점을 weld하고 모서리에 bevel을 적용했다. 12개 차륜에 총 96개 림 체결부 형상을 추가했다. 기존 부품 그룹 Hull/Turret/Gun/RunningGear/Markings는 유지한다. 움직임은 추가하지 않았다.

## 정직한 품질 판정
사진 투영 왜곡이 사라지고 재질 구분과 모서리 하이라이트가 정돈됐지만, 이 결과는 여전히 단순화된 장비 모형으로 보인다. 위장 패턴은 실장비 패턴 스캔이 아니며 차체·포탑 실루엣의 정밀 재구축은 완료하지 않았다. 원본 사진 한 장은 위장망이 넓게 가리고 있어 검증 가능한 측면/상면/후면 정보를 제공하지 않는다. 이번 보완만으로 사용자가 요청한 실사화 목표를 달성했다고 주장할 수 없다. 기본 자산 교체를 권하지 않으며, 기존 AI 참고판 버전과 비교 가능한 별도 후보로만 보관한다.

다음 단계에는 가림 없는 사용 허가된 다각도 사진/모델을 확보하고, 실루엣을 비교하며 개별 부품을 재구축해야 한다. 개체 수가 많다는 것과 실제 장비처럼 보인다는 것은 다르다.
