# 비공개 행사 운영 제안

현재 구현은 접근 권한, 저장소 공개 범위, DNS, GitHub Pages 배포 설정을 변경하지 않는다.

비공개 운영이 필요하면 조직이 승인한 인증 서비스를 이용하는 서버 또는 역방향 프록시 앞에 사이트를 둔다. HTML뿐 아니라 `/assets/`, `/media/`, `/models/`, `/lighting/`, 지도 관련 자산의 모든 요청에 같은 인증·권한 검사를 적용한다. 프런트엔드 비밀번호나 숨겨진 URL은 인증 게이트로 취급하지 않는다. 브라우저 번들에는 비밀 키를 넣지 않는다.

운영 결정이 필요한 사항:
- 승인된 사용자·조직 계정 범위, 기관 인증 체계, 접속 기기와 세션 만료 정책.
- 행사 외부 네트워크 사용 여부, 실제 영상·3D 자료의 오프라인 제공 허가.
- 권리 승인된 자료만 포함한 배포 묶음과 외부 서비스 접속 허용 범위.
- 장애 시 승인된 로컬 영상·포스터로 전환하는 운영 담당자와 절차.

행사 운영안이 확정되고 사용자가 승인한 뒤 실제 인증 구성과 배포를 별도 작업으로 진행한다. 특정 공급자나 비용은 이번 구현에서 확정하지 않았다.
