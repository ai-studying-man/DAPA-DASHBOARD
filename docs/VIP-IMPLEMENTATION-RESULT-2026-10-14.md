# 간부·전시회 시연 개선 구현 결과

2026-10-14 · 로컬 구현 · 공개 배포 미실행

## 반영한 내용

- 홈 제목을 **K-방산의 중심, 방위사업청**으로 변경했습니다. 기존 로고·순위·세로 키오스크 구조를 유지합니다.
- 소개 영상은 기존 사용자 제공 23.5초 MP4를 무음 자동 반복 재생합니다. 실패 시 실제 포스터와 재생 재시도·페이지 이동을 제공합니다.
- 전시회·세미나·현장 시연 선택 화면에서 실제 장비 영상 → 위성 지형과 3D 관찰 → 공개 수출 이야기로 직접 이동합니다.
- 3D 집중 모드는 설명 패널을 접어 장면을 확대합니다. 음성 정지, 시점 복원, 수출 사례 이동은 유지됩니다.
- 한국어·영어·일본어·중국어(간체)를 앱 전체 설명·접근성 문구·안내에 적용하고 선택을 저장합니다. 음성은 선택 언어와 일치하는 기기 음성만 사용합니다.
- 3D 로딩 10초 초과·초기화 실패·네트워크 오류·그래픽 연결 끊김에 재시도/소개 영상/돌아가기 동작을 제공합니다.
- 폴란드 K2 2022·2025 이행계약 카드에 수량과 당시 납품 계획을 구분해 표시합니다. 실제 납품 완료나 기본계약 1,000대를 확정 수출로 표시하지 않습니다.
- 자산 40건의 출처·권리 상태와 영상 교체, 비공개 운영 방안을 문서화했습니다.

## 검증 범위

- production build, JavaScript 문법 검사, 번역 리소스와 23개 장비의 설명·관계·연혁 렌더 점검.
- 실제 인앱 브라우저의 영상 자동 재생, 홈 진입, 키보드 이동, 언어 변경·재로드 저장, 메뉴 접기·복원, 장비 시연과 수출 화면 연결.
- 실제 FA-50 위성 지형/외형 재구성 표시 및 집중 모드 관찰. 외부 지도 타일이 늦으면 실제 10초 초과 복구 화면으로 전환되며, 영상 대체 재생을 확인했습니다.
- 실제 소개 영상 누락 상태는 임시 경로로 확인한 후 원래 MP4 경로를 복구했습니다.
- SceneWatch 분류·수동 재시도·중단·WebGL 미지원 등은 임시 스텁 점검으로 검증했습니다. 이 점검은 실제 GPU context loss 검증이 아닙니다.
- 화면별 PNG·동작 관찰·독립 검토 결과는 `docs/evidence/vip-v13`에 기록합니다.

## 별도 확보·검증할 자료

- 새 약 10초 인트로와 네 언어 VTT 자막은 미제공입니다. 현재 영상으로 동작하며 존재하지 않는 파일은 연결하지 않았습니다.
- 원어민 번역 감수와 행사장 Windows/키오스크의 네 언어 음성 출력, 실제 GPU 복구·장시간 운영 검증은 미완료입니다.
- 현재 3D는 공개 사진·치수 기반 외형 재구성입니다. 제조사 승인 CAD, 실측 실내, 운용·성능 시뮬레이션을 구현한 것으로 표시하지 않습니다.
- 기관 로고 및 사용자 영상의 행사 사용 승인, 조건 미확정 자산은 권리 문서의 상태에 따라 확인해야 합니다.
- 비공개 인증·접근 제어는 문서 제안만 작성했습니다. 저장소/Pages 공개 범위와 인증 설정을 변경하지 않았습니다.

## 최종 화면 검증 기록

- 66개 본 검토 PNG와 추가 390×844 홈 PNG: 375×900, 768×1024, 1280×900, 1080×1920, 1920×1080의 스토리/시연/언어 상태를 수록했습니다.
- 브라우저의 일반 캡처가 가상 뷰포트를 일부 잘라 저장하는 문제가 있어 전체 페이지 캡처를 사용했습니다. 추가 페이지 높이가 있는 경우 원본 픽셀의 좌측 상단에서 뷰포트 크기로 자르며, 확대·축소하지 않았습니다. 원본 크기와 방법을 captures.json에 기록했습니다.
- 독립 검토에서 찾은 탐색 제목 번역 누락·중국어 쉼표 단독 줄바꿈·캡처 크기 문제를 수정하고 해당 화면을 다시 캡처했습니다.
- 최종 탐색 모드 제목/설명은 영어·일본어·중국어 리소스 점검을 통과했습니다. UI 591개 + 장비/자료 285개 항목입니다.
- 외부 타일 지연 및 실제 행사장 하드웨어 확인은 남아 있습니다. 최종 코드에서 정상 FA-50 장면과 확대 모드를 관찰했으며, 정상과 실패를 별도 기록했습니다.

- 수정 후 독립 기능·디자인 검토와 CJK 화면 검토 모두 PASS입니다. 전 단계의 REVISE 결과는 개선 이력을 위해 보존하고 최종 검토 기록으로 대체했습니다.
- 브라우저 실제 200% 확대, 행사장 장시간 실행, 네 언어 실제 스피커 출력은 수행하지 못했습니다. 원본 브라우저 화면 크기는 작업 종료 전 복원했습니다.
- 커밋·push·GitHub Pages 배포는 이번 변경에 대해 실행하지 않았습니다. 미리보기와 소스는 로컬에 저장되어 있습니다.
