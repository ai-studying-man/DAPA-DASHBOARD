# K2 · K9 전시용 모델링 체험

## 현재 구현 범위

공개 외형 자료를 참고한 독립 제작 GLB 초안이다. 제조사 CAD, 실측 모델, 정면·측면·상면 도면 정합 완료 모델이 아니다. Blender 원본은 제공되지 않았으며 이번 산출물은 JavaScript 형상 생성기로 제작했다. 사진을 평면에 붙여 3D처럼 표시하는 방식이 아니라 실제 메시와 재질, 독립 피벗을 가진다.

- K2: 낮은 포탑과 전면 장갑 외형, 장포신, 6개 차륜/측.
- K9: 높고 큰 포탑 외형, 긴 포신과 제퇴기, 6개 차륜/측.
- 공통: 차체·포탑·포신·주행부·전시 마킹을 분리. 정면/후면/좌/우/상면/초기 시점, 자유 회전·확대, 구조선, 부품 강조·분리, 포탑/포신 조절, 예시 동작, 실사 비교.
- 조절 각도, 동작 속도, 분리 간격은 UI 설명용 값이다. 사격·기동 물리, 실제 조작 절차, 내부 구조 및 탑승자 시점은 구현하지 않았다.
- 위성 지도에도 동일 GLB를 표시하되 지도 위치는 기존 전시용 위치를 사용한다.

## 파일과 재생성

`node scripts/create-ground-models.mjs`로 두 GLB와 메타데이터를 재생성한다. 런타임은 `src/model-studio.js`, UI와 4개 언어는 `src/model-studio-ui.js`, 자산 연결은 `src/vehicle-models.js`이다. 모델은 각각 약 1.5 MB, 약 2만 삼각형이다. 원본 사진과 모델의 출처·사용 조건은 각각 `public/models/*-ATTRIBUTION.md`에 기록했다.

## Blender 정밀 모델로 교체하기

1. 사용 허가된 정면·측면·상면 자료와 치수, 외형 판형을 확보하고 출처 및 허가 범위를 기록한다.
2. Blender에서 현재 GLB를 임포트하거나 새 모델을 만든다. 현재 모델의 비율을 검증된 치수로 간주하지 않는다.
3. 미터 단위, +Y 위, -Z 전방을 런타임 기준으로 맞춘다. Blender의 Z-up 변환은 glTF 내보내기 후 확인한다.
4. `Hull`, `Turret`, `Gun`, `RunningGear`, `Markings` 이름을 유지한다. Gun은 Turret의 하위이며 포탑 회전 중심은 Y축, 포신 회전 중심은 로컬 X축이다. 변환 적용 시 피벗을 메시 중심으로 덮어쓰지 않는다.
5. 실사 비교로 실루엣·차륜·포탑·포신·안테나 위치를 정합한다. 허가된 PBR 텍스처와 UV, 노멀, 필요 시 LOD를 추가한다. 현 초안은 절차적 색 재질이며 사진 수준의 표면 재현은 아니다.
6. GLB로 내보내고 기존 파일을 교체한다. 로컬 모델이므로 외부 임베드 없이 동작하지만 지도 영상은 네트워크를 사용한다.
7. 모바일에서 화면 회전, 6개 시점, 포탑/포신 피벗, 부품 분리 후 복원, 실패 후 재시도, 화면 닫기 후 자원 해제를 확인한다. 출처·라이선스와 검증 수준 문구도 함께 갱신한다.
