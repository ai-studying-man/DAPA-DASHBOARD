# 자료 기반 다국어 3D 관람 구현

1. 완료: 공개 근거를 4개 대표 모델의 12개 부위 설명·다국어 데이터로 연결.
2. 완료: 언어별 음성 선택과 자막, 부위 카메라 관람, 국내·해외 사례 원문 연결 구현.
3. 완료: production build 및 문법 검사 통과, 72개 실제 화면과 언어 전환·취소·오류 처리 확인, 독립 리뷰 2개 PASS. 배포는 GitHub Pages 워크플로로 진행.

범위: KO/EN/JA/ZH 안내, 공개 자료 재구성 모델. 제조사 CAD·검증 내부 구조는 확보되지 않았으므로 추정 관찰 위치를 명시한다.

현재 브라우저 음성 inventory: 한국어 사용 가능, 영어·일본어·중국어 미설치. 자막은 4개 언어 모두 제공하며, 해당 언어 음성이 설치된 브라우저에서는 TTS를 재생한다. 미설치 상태에서는 자동 관람을 중지하고 다른 언어로 대체하지 않는다. 실제 스피커 청취 품질은 검증하지 않았다.

한국어 발화도 현재 내장 브라우저에서 오류로 종료됐다. 성공한 TTS 재생과 음성 종료 후 자동 부위 전환은 별도 호환 브라우저·전시장 음성 환경에서 확인해야 한다.
