# 전체39종 검증

대상: 대시보드23종과 장비목록21종의 합집합39종. 해외 비교/명칭 확인/위성 개념형 포함. 실사 형상·제조사 인증과 **별도의 제작·웹 기능 검증**이다.

모델 원본과 각 결과는 [체계별 감사](FLEET-ASSET-STATUS.json), 작업·SHA·재개는 [진행 기록](FLEET-PROGRESS.md)에 기록한다. 세 시점117개 렌더, 비교39개 보드와 전체 웹 캡처는 `docs/modeling/fleet/`에 있다.

원통 cap n-gon은 삼각분할하여 신규12종 normal tangent 누락을 해결했다. 기존 일부 퇴화 UV는 해당 프리미티브의 normal map만 명시적으로 flat 변형으로 처리했다. 원본의 메시·색·라이선스는 유지했다. 신규 normal은 독립 제작 기본값이며 실측 요철이나 AO 베이크가 아니다.

브라우저 검증은 이 PC Chrome의 뷰포트/터치 에뮬레이션이다. 실제 저성능 휴대폰·장시간 키오스크·외부 위성 타일·실운용 물리의 인증이 아니다. `QA_FPS=1`이면 첫 뷰포트의 각 모델에서 실제 렌더 callback60프레임의 fps/p95 간격을 별도 기록한다. 평균 FPS만으로 품질을 합격 처리하지 않는다. LOD/KTX2와 실측 사진 정합은 후속 성능·정확도 개선 항목이다.
