# 모바일 내용별 페이지 구성 v16

## 구성

1. 홈: 제목, 영상, 수출 순위, 다음 버튼, 4개 언어 선택.
2. 관람 안내: 제목 두 줄과 설명 가운데 정렬, 전군 현황과 관람 방식의 간격 분리.
3–6. 육군 K2 / 해군 도산안창호급 / 공군 FA-50 / 해병대 KAAV: 한 페이지에 장비 한 대, 온전한 사진과 시연 버튼.
7–8. 한반도 소개 / 한반도 3D 지도: 소개의 탐색 버튼이 지도 페이지로 이동; 지도 아래 환경과 돌아가기 버튼.
9–11. 세계 소개 / 대한민국과 6개국 지도 / 수출 체계 선택: 설명, 지도, 장비 선택을 분리.
12–14. 장비 찾기 소개 / 군별 선택 / 환경별 선택: 중앙 설명과 별도 선택 화면. 체계 바로 선택은 기존 전군 현황 목록에 연결.

## 확인 범위

- 375×667 모바일에서 14개 기본 페이지의 중앙 영역 scrollHeight=clientHeight, scrollWidth=clientWidth. 기본 내용이 화면 끝에서 잘리거나 가로 넘침을 만들지 않음을 기록.
- 768×1024 / 1280×900 전체 페이지 관찰. PC 지도 카드 너비1134px 확인.
- 375×560 한국어·영어 홈에서 다음·언어 버튼 확인. 영어 다음 버튼 하단496px, 언어 선택548px로 화면 안에 들어감.
- 소개→지도→공중 필터→전시 지도 복귀→소개 복귀, 기존 K2 실사 시연 열기·닫기 관찰.
- 지도는 실제 외부 지형/영상에 의존하며 준비 상태도 그대로 기록. 준비 화면 캡처를 정상 시뮬레이션으로 주장하지 않음.
- 상세 근거 펼치기/기존 도감은 긴 내용 스크롤을 유지. 실제 터치 기기·Safari 주소창·장시간 GPU·네 언어 음성은 별도 미검증.
- 로컬 변경이며 이번 작업에서 commit/push/공개 배포하지 않음.
