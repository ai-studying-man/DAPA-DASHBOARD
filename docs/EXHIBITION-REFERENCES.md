# 공개 전시 사례와 적용 범위

- [한화 MADEX 2025 공식 전시 발표](https://www.hanwha.com/newsroom/news/press-releases/hanwha-presents-integrated-defense-vision-at-madex-2025.do): 함정·잠수함·전투체계·무인체계·추진 기술을 통합 전시. 본 구현은 장비 외형, 역할, 공개 참여기업을 하나의 관람 화면에 연결하는 구성을 참고했다.
- [한화 ADEX 2025 공식 발표](https://www.hanwha.co.kr/newsroom/media_center/news/article.do?seq=15193): LAND·PGM·AIR·NAVAL·SPACE 등 영역별 전시를 참고하여 지상·해상·공중·우주 필터와 체계 연결을 확장했다.

공식 전시 화면을 복제하거나 공식 성능·운용 시뮬레이터로 인증된 결과가 아니다. 수출 관계는 개별 공개 근거의 계약·공급 사례이며 전체 수출 통계나 실제 운송 경로가 아니다. 대한민국의 위상과 기술 다양성을 설명하는 공개 전시 용도이다.
