# 전시 키오스크용 전군 공개 체계 현황

## 목표와 반영 범위

PC·모바일 브라우저에서 쓰고 최종적으로 전시장 키오스크에서 터치·스크롤로 관람하는 홍보용 웹앱입니다. 공모전 제출물 대신 실제 기능 구현을 우선했습니다. 기존 홈 영상·군별 대표 시연·지도·3D·수출·다국어 화면을 유지하며 별도 전군 현황 모드를 추가했습니다.

- 진입: 홈 다음 화면의 **전군 무기체계 현황 보기**, 장비 찾기 화면, 탐색 메뉴의 **전군 현황**.
- 경로: http://127.0.0.1:5173/?view=forces
- 육군·해군·공군·해병대·공통/합동 선택, 기존 환경/군/검색 필터 교차 사용.
- 장비 선택 → 기존 상세 설명/출처/3D 시연, 현황으로 돌아가기 → 선택한 카드 초점 복귀.
- 장비를 선택한 뒤에만 상세/외부 3D를 불러옵니다. 단일 본문 세로 스크롤, 48px 이상 조작, 모바일 언어·메뉴·설정·홈 버튼 두 줄 구성.
- 한국어·영어·일본어·중국어 설명과 기존 언어 저장을 유지합니다.

## 공개 자료 분류

현재 **23개 고유 체계**를 담았습니다. 전체 군 보유량/실시간 배치/완전한 국가 무기 목록을 집계한 화면은 아닙니다. 수출형·개발 사업도 포함하며 AS21 레드백은 수출형, 누리호는 민간 우주 기반으로 표시합니다.

| 분류 | 수록 체계 수 |
|---|---:|
| 육군 분류 | 9 |
| 해군 분류 | 3 |
| 공군 분류 | 6 |
| 해병대 분류 | 3 |
| 합동·우주 기반 | 4 |
| 공통·합동 모아보기 | 6 |

K9·천무는 육군·해병대 두 분류에 들어갑니다. 전체 합계는 중복을 제거한 23개입니다. 공통·합동 6개는 군 간 공개 사례 2개와 합동/우주 기반 4개를 모은 값이며, 네 군 모두의 운용을 확인했다는 뜻이 아닙니다.

신규 근거: [대한민국 정부 공식 브리핑, 2026-06-24](https://www.korea.kr/news/policyNewsView.do?newsId=148967061)의 해병대 공개 장비 사례에서 K9·천무를 확인했습니다. 해당 원문을 두 체계의 자료 목록에 연결했습니다. 실제 부대 위치·수량은 지도에 추가하지 않았습니다. 기존 지도의 군 필터에도 같은 데이터가 반영됩니다.

## 확인 기록

- 최종 production build 성공. 신규 테스트 파일은 추가하지 않았습니다.
- 실제 브라우저: 여섯 군별 상태 × 375/768/1280px, 1080×1920 세로 전시 화면, 네 언어 현황·공통 설명, 빈 검색·초기화, 육군+공중 교차 필터.
- 해병대 결과: K9/천무/상륙돌격장갑차. 합동: 425/초소형위성/누리호/ANASIS-II. 육군+공중: 수리온/LAH.
- 단일 본문 스크롤, 키보드 선택·카드 초점 복귀, 직접 링크 재로드를 확인했습니다.
- 현황 카드에서 FA-50 기존 시연으로 연결해 정상 3D 준비 완료를 관찰했습니다. 추가 연결에서는 외부 지도 지연에 따른 10초 초과 복구 상태도 관찰했습니다. 최종 모달 캡처는 이 지연 상태를 숨기지 않고 기록하며 재시도/영상 대체/돌아가기 기능을 유지합니다.
- 실제 손가락 터치 패널, 행사장 GPU·장시간 동작·네 언어 스피커 출력은 기기 미제공으로 미검증입니다. 브라우저 스크롤과 네이티브 버튼·pan-y 구현을 확인한 범위입니다.
- 공개 모델/지도는 외부 서비스 연결이 필요할 수 있습니다. 기존 실패 복구와 자료 유형·권리 표시를 유지합니다.
- 이번 변경은 로컬 구현이며 커밋·push·공개 배포를 실행하지 않았습니다.

화면 및 검토 기록: `docs/evidence/forces-v14`. 원본 캡처를 PNG로 변환하며 뷰포트보다 큰 경우 좌측 상단의 원본 픽셀을 해당 크기로 자릅니다. 확대·축소하지 않으며 원본 크기를 manifest에 기록했습니다.

수정 후 KO/EN/JA/ZH 375px의 본문 clientWidth=scrollWidth=360px로 가로 넘침이 없음을 실제 DOM에서 확인했습니다. 상세 복귀 시 초점은 선택한 카드로, 상세 패널은 숨김으로 복원됩니다. 외국어 헤더/검색은 짧은 문구, 환경 필터는 줄바꿈으로 보강했습니다.

독립 기능 검토 APPROVE 및 화면 검토 PASS. 캡처 오류 두 장을 재기록하고 42개 이미지·8개 소스 해시를 확인했습니다. 최종 검토 근거는 `docs/evidence/forces-v14/review-ledger.json`에 기록했습니다.
