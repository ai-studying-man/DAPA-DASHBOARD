# 자료 기반 다국어 3D 관람 확인

## 구현 범위

- KAAV, FA-50, 도산안창호급, 누리호의 12개 외형 관찰 부위.
- 한국어·영어·일본어·중국어 설명, 부위 이름, 안내 조작 및 자막.
- 실제 Cesium GLB 카메라와 단일 부위 마커. DEM 갱신 때 마커·카메라 높이 보정.
- 한화 WebGL 쇼룸, KAI 훈련체계, KARI VR, Naval XPlore, Saab WAD 사례의 원문과 적용 범위 연결.
- 음성 언어 변경·중지·체계 변경·시점 변경·닫기·화면 비활성 시 이전 발화와 자동 진행 취소.

## 실제 화면 관찰

Production build 및 변경 JavaScript 문법 검사 통과. 테스트를 추가하거나 실행하지 않았다. LSP는 이전에 사용자가 설치를 거절한 상태다.

`docs/evidence/guide-v9/manifest.json`에 72개 PNG 기록: 4개 체계 × 4개 언어 × 3개 화면 폭(48개), 데스크톱 추가 부위(12개), 모바일·태블릿 현장(8개), 음성 오류 상태(4개). 1280×960, 768×1024, 375×900 크기를 직접 확인했다. JPEG로 반환된 브라우저 캡처를 PNG로 정규화하고 파일·소스 SHA-256을 기록했다. 관찰한 모바일·태블릿 가로 넘침은 0이다.

부위 선택, 4개 언어 전환, 선택 상태, 원문 연결 표시, 오류 후 재생 상태 해제, Escape 닫기를 실제 브라우저로 확인했다. 누리호 하부 근접 시점은 지형에 가려져 1단 전체 구성 관찰로 조정했다. 발사대 CAD·내부 실측 모델을 추가한 것은 아니다.

언어 상태 이미지 diff는 한국어와 영어 화면의 의도된 내용 차이를 비교한다. dimensionsMatch=true, alphaChannelIntact=true, diffRatio=0.1632. 외부 디자인과 픽셀 일치 점수로 해석하지 않는다.

## 음성 확인의 한계

현재 브라우저의 한국어 음성 목록은 있으나 실제 발화가 오류로 종료됐다. 영어·일본어·중국어 음성은 미설치 상태다. 4개 언어 모두 오류 안내·자막 유지·재생 상태 해제는 확인했다. 성공한 음성 재생, 발음 품질, 발화 종료 후 자동 부위 전환은 이 환경에서 검증하지 못했다. 전시장 브라우저의 언어별 음성 설치와 재생 확인 또는 사용권이 확보된 사전 생성 음성 파일이 필요하다.

모델은 공개 사진·치수 기반 재구성, 좌표는 추정 관찰 위치다. 제조사 CAD·검증 실내·장비 성능 시뮬레이션으로 표시하지 않는다. 지도 타일과 원문은 네트워크에 의존한다. 현장 GPU·4K·장시간 운영과 실제 스피커 청취 품질은 확인 범위 밖이다.

## 독립 리뷰

- Pass A: PASS. 72개 캡처와 7개 소스 해시 확인. 실제 모델, 언어별 자막, 취소·오류 처리, 토큰 기반 스타일에 차단 항목 없음. 음성 성공을 검증했다고 표현하지 않을 것.
- Pass B: PASS. 최종 72개 캡처와 원본 크기 CJK·영어 모바일 화면 확인. 긴 영어 버튼 줄바꿈 수정 후 차단 항목 없음. 이 판정은 시각 확인이며 성공한 음성 재생을 입증하지 않는다.

모바일의 긴 영어 누리호 부위 버튼이 카드 여백 밖으로 나오는 문제를 수정했다. 최종 48개 언어 화면의 버튼 경계를 실제 DOM으로 확인했으며 모두 카드 내부다. 수정 후 72개 화면을 새로 캡처했다.
