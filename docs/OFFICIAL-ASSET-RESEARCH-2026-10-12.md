## 조종석 구현에서 지켜야 하는 구분

FA-50 공식 브로슈어의 조종석 그림은 계기 위치를 확인하는 참고 자료다. HUD/IUFC, 경고등, 착륙장치 패널, 주의 패널, 사이드스틱, 스로틀 그립 등이 그림으로 제시되어 있다. 모든 수출형의 계기판이 동일하거나 버튼 동작·실측 좌표를 검증했다고 볼 수 없다. 브로슈어의 Block 50/60/70 발전 방향도 이미 인도된 모든 기체의 내부 구성으로 일반화하지 않는다. 기체 관찰 시점과 실제 내부 재현을 따로 표시한다.

## 추가 확보 절차

1. 해당 제조사 홍보·전시 또는 사업 담당자에게 공개 전시용 외형 메시와 공개 가능한 내부 파노라마/조종석 자료 제공을 요청한다. 공식 페이지의 연락 경로를 사용하며 이 조사에서 연락 메시지는 보내지 않았다.
2. 장비 형식·개량형·촬영일·좌석 위치·계기 구성의 검증 범위를 함께 받는다. 외형만 제공받으면 내부 실측 모델이라고 표시하지 않는다.
3. 공개 웹에서 사용자가 파일을 내려받을 수 있는 GLB 배포, 수정·경량화, 전시회/상업 활용, 출처 표시, 재배포 범위에 대한 서면 허가를 받는다. 외부 링크 열람 허가와 원본 파일 재배포 허가를 구분한다.
4. 제공 원본·허가 사본·파일 해시·단위와 축·검증된 시점 좌표를 기록한 뒤 기존 전시 재구성 모델을 해당 자산으로 교체한다.

누리호·KAAV 등 저장소의 `*-reference.glb`는 공개 사진/자료를 참고해 프로젝트가 작성한 전시용 외형이며 제조사에서 확보한 CAD가 아니다.

## UI 표시용 FA-50 구성 항목

전자 PDF의 2번째 페이지(표지 포함 7개 PDF 페이지 중 2번째)를 확인했다. 이 페이지에는 별도의 인쇄 쪽번호가 보이지 않으므로 UI에서는 **전자 PDF 2쪽**으로 표시한다. 오른쪽 하단의 FA-50/F-16 C/D 비교 그림 중 FA-50 쪽에 실제로 표기된 `HUD/IUFC`, `Warning Lights`, `L/G Panel`, `Side Stick`, `Throttle Grip` 다섯 항목을 `src/official-resources.js`에 기록했다. 한국어 명칭은 설명용 번역이며 원문 표기를 짧은 설명에 유지한다. 버튼 동작·좌표·크기·납품형별 구성이나 장치 성능을 검증했다는 의미가 아니다.
