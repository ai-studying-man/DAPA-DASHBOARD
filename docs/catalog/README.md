# 공개 체계·자산 확장 기록

2026-10-12 확인. `src/catalog-expansion.js`에 공식 출처, 13개 추가 체계, 기관 관계, 수출 사건을 기록했다. 기존 10개를 포함해 23개 체계다. 위치는 설명용 전시 좌표이며 배치 위치가 아니다.

## 수출 사례

- 폴란드: 기존 K2·K9·천무·FA-50 계약 기록 유지.
- 루마니아: K9·K10 2024년 공급 계약, 한화 공식 계약 발표.
- 이집트: K9·K10 2022년 패키지 계약, 한화 공식 발표.
- 호주: 레드백 2023년 129대 계약, 호주 국방부 발표. 인도 완료로 표시하지 않는다.
- 말레이시아: FA-50 2023년 18대 계약, 대한민국 정부 Korea.net 발표.
- 필리핀: KAAV 2016년 공급 사례, 한화 Global Capabilities 브로슈어 표의 연도. 계약일이나 인도 완료일로 추정하지 않는다.

공식 제품·보고서에 나오는 수출 목표를 확정 실적으로 추가하지 않았다. 국가 수는 여섯이며 실제 전체 수출국가 통계가 아니다.

## 이미지

`src/catalog-assets.js`에는 Wikimedia Commons API에서 원본 파일, 저자, 라이선스를 확인한 15개 실사진을 기록했다. 전체 API 기록은 `wikimedia-license-records.json`, K9 별도 조회는 `k9-license-record.json`이다. 전시 현장의 외부 사진 연결 의존을 줄이기 위해 15개 사진을 최대1280px WebP로 저장했다. 원본 URL·저자·라이선스·변환과 SHA-256은 local-image-manifest.json에 기록한다. CC BY-SA 배포 변환본은 같은 라이선스를 유지한다.

K9 외부 3D 업로드의 원출처를 확정하지 못했으므로 실사진으로 교체했다. KAAV 사진은 한국 해병대 상륙훈련의 실제 장비다. 수리온 사진은 시제기, 누리호 사진은 2021년 발사 장면이다. 사진을 3D 메시 또는 검증된 시뮬레이션으로 표시하지 않는다.

425·초소형위성·ANASIS 위성 본체·충남함의 재사용 허가와 정확한 식별을 만족하는 이미지는 이 조사에서 확보하지 못했다. 일반 위성이나 다른 함정 사진으로 대체하지 않았다. ANASIS-II는 국내 지상 통신체계 구성품 사업을 설명하며 위성 본체를 국내 제작품으로 단정하지 않는다. 누리호는 민간 우주 기반이며 무기로 분류하지 않는다.
