# 객체 중심 3D 체계 시연

2026-10-08. 팔란티어의 [Ontology core concepts](https://www.palantir.com/docs/foundry/ontology/core-concepts), [Link types overview](https://www.palantir.com/docs/foundry/object-link-types/link-types-overview), [Ontology overview](https://www.palantir.com/docs/foundry/ontology/overview/)를 참고했다. 공개 문서는 객체·속성·관계·동작으로 데이터를 연결하고 객체별 탐색 화면을 구성하는 개념을 설명한다. 본 시연은 그 개념을 HTML5 전시 콘텐츠에 적용한 로컬 구현이며 팔란티어 Foundry, AIP 또는 공식 제품의 3D 화면을 복제·탑재한 것은 아니다.

## 관람객 흐름

지도 위 체계 모형 또는 라벨 클릭 → 해당 체계 3D 시연 → 외형/외형 구성/역할 중 선택 → 시연 재생·중지·시점 복원 → 연관 체계 버튼으로 다음 객체의 시연. 홈·목록에서 선택한 체계는 상세의 ‘3D 체계 시연’으로 진입한다. 지도 돌아가기와 Escape는 기존 지도·상세를 유지하고 renderer를 반환한다. 음성 전시도 계속 사용 가능하다.

외형 구성은 설명 모형의 조각을 펼치는 표현이며 실물 내부 부품의 분해도는 아니다. 역할 시연은 6초의 단순 이동 또는 관측 플랫폼 방향 변화로 구성한다. 사용자가 눌러야 재생하고, 닫기·선택 변경·중지·탭 비활성·모션 감소 설정에서 정지한다. 실제 속도·사거리·무기 효과·교전·임무 계획 또는 제조사 검증 시뮬레이션이 아니다.

## 객체와 관계

`src/ontology.js`는 System, Organization, Project, Region, Source 객체를 고유 ID로 정의한다. 소속 사업, 공개 참여기관, 공개 산업 연결, 문서 근거와 체계 간 공통 환경/공통 참여기업 관계에 타입과 근거를 기록한다. 중복 객체는 ID로 통합하고 체계 간 대칭 관계는 한 번 저장한다. 단순 문자열 시각화에서 관계의 종류·근거를 확인하고 관련 객체로 이동할 수 있게 확장했다. 아직 OWL 추론, Foundry OSDK, 서버 동기화, 관계 변경 트랜잭션은 없다.

- K2 → K9: 같은 지상 활동 환경이라는 설명용 분류 관계.
- K9 → 천무/상륙돌격장갑차: 공개자료의 공통 참여기업(한화에어로스페이스) 관계. 각각의 근거 링크를 제공한다. 상륙돌격장갑차 참여 역할은 RCWS 사업에 한정한다.
- FA-50 → MUAV: 같은 공중 활동 환경 관계.
- 425사업 → 초소형위성체계: 같은 우주 활동 환경 관계.

위 관계는 공동 작전·통신 호환성·탐지와 타격 연동을 입증하지 않는다. 실제 체계 연동 시연을 추가하려면 공개된 연동 근거와 허가된 시연 콘텐츠를 별도로 확보해야 한다. 현재 자료에서 관계를 찾지 못하면 이를 명시하고 새로운 연결을 추정하지 않는다.

현재 9개 체계의 모델은 직접 작성한 설명용 모형이다. 제조사 사용 허가를 받은 정밀 glTF 모델·시연 영상·검수한 외형 구성 데이터로 발전시키는 것이 다음 제작 단계다. 데이터 범위는 기존 12개 공개 근거와 4개 산업 도시, 폴란드 1개국 사례를 유지한다.
