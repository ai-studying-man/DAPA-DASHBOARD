실제 전시 터치 패널, 멀티터치 지도 제스처, 장시간 무인 운영, 저사양 GPU, 브라우저별 전체화면 및 현장 해상도 테스트는 아직 수행하지 않았습니다. 운영 배포 전에 현장 검증이 필요합니다.

독립 검토 보고서는 `review-integrity-final.md`, `review-visual-final.md`에 저장합니다. 기존 검토의 REVISE는 캡처 러너 변수 오류·오래된 캡처·검사 원본 누락에 대한 기록이며 최종 재검증 자료를 별도로 제공합니다.

## 밝은 화면 및 탐색 개편 검증

최종 근거는 `docs/evidence/light-v2/report.json`입니다. 34개 새 캡처: 첫 화면과 다섯 탐색 방식의 375/768/1280/1920 화면, K2/위성 비교, 검색 빈 결과, 하단 메뉴, 1080×1920 세로/좌측/전시, 4K, hover/focus, 제어된 WebGL 오류입니다.

첫 군별·환경별 카드의 필터 적용, 체계 직접 선택, 처음으로 복귀, 미래 발표 계획 구분을 확인했습니다. 브라우저 오류 0, 14개 axe 조합 위반 0입니다. 기존 지도 확대·회전·검색·필터·설정·터치 회귀 검사도 통과했습니다. 작은 화면에서 지도와 목록이 겹치지 않도록 상하 배치의 스크롤 소유권을 수정했습니다.

첫 화면은 지도 선택 전 Three.js를 로드하지 않습니다. 실제 Chrome Lighthouse: 모바일 유효 3회 모두 네 범주 100. 데스크톱 유효 3회 성능 100/100/77, 나머지 범주 모두 100으로 중앙값은 모두 100입니다. 데스크톱 최초 3번째 측정은 Chrome interstitial 오류로 무효였으며 원본과 재측정 결과를 모두 보관했습니다. 이는 첫 선택 화면의 결과이며 3D 지도 선택 이후의 성능 보장으로 일반화하지 않습니다. 이전 어두운 지도 화면의 성능 68 기록도 삭제하지 않았습니다.

실제 키오스크 장비와 모든 체계의 변천 자료는 여전히 별도 검증·확장 범위입니다. 독립 검토는 같은 폴더의 `review-integrity.md`, `review-visual.md`에 기록합니다.

데스크톱 재측정 성능 77에는 초기 레이아웃 이동(CLS 0.628)이 포함됩니다. 측정 편차와 최초 화면 안정성은 개선 대상으로 남겨두며, 중앙값 100을 모든 실행의 품질 보장으로 표현하지 않습니다.

## 관람객 전시 v3 검증

2026-10-08 최종 프로덕션 빌드: 성공. 근거는 `docs/evidence/exhibition-v3/report.json`, `exhibition-report.json`과 원본 axe JSON이다. 현재 캡처는 각각 34개와 22개이며 375/768/1280/1920, 세로 1080×1920, 4K를 포함한다. 기존 다섯 탐색 방식과 홈/환경 탭/음성 전시의 22개 axe 조합 모두 위반 0, 두 브라우저 러너 pageerror 0.

다섯 음성 전시 장면, 자막·중지·닫기, 아홉 체계의 모델 생성과 참여기관 원문 링크, 네 도시의 관련 체계 필터, 모델 드래그, 검색·선택 시 음성 취소를 Chrome에서 확인했다. Microsoft Heami 한국어 음성의 onstart 상태를 확인했으나 스피커에서 들리는 실제 음질·음량은 검증하지 않았다. `voice-boundaries.json`과 `voice-auto.json`은 음성 API 대체를 사용한 결정적 모의 검사로, 한국어 음성 없음·API 없음·오류·음성 로딩 중 취소·지연 onend 무시·선택적 자동 넘김과 취소를 확인했다. 실제 하드웨어 결과로 해석하지 않는다.

독립 검토에서 발견한 지연 세계 지도 응답과 라벨 중첩을 수정했다. 모든 모드 변경에서 대기 중인 지도의 대상 모드를 갱신하고, 한국어 폰트 로딩 후 라벨 배치를 다시 계산하며, 지도 라벨의 위치 transform은 애니메이션 없이 반영한다. 좁은 공간에 배치할 수 없는 라벨은 숨기고 지도 외부 전체 체계 목록과 지역 버튼으로 접근한다. 이전 REVISE 보고서는 수정 전 기록이며 최종 판정은 `verified-visual-review.md`, `verified-integrity-review.md`를 확인한다.

현재 데이터는 9개 체계, 12개 공개 근거, 4개 산업 도시 연결, 폴란드 1개국 사례다. 전체 국내 사업/세계 수출 데이터베이스가 아니다. 실제 제조사 CAD, 실제 지형 고도, 현장 키오스크·장시간 운영, 스피커 음향은 후속 검증 범위다. 이 버전에서 Lighthouse 재측정은 수행하지 않았으며 v2 결과를 v3 성능 점수로 주장하지 않는다.

## 객체 중심 체계 시연 v4

최종 빌드 성공. docs/evidence/ontology-v4/report.json의 실제 Chrome 검사: 375/768/1280/1920에서 외형·외형 구성·역할 재생·완료·관계 이동, 아홉 체계 객체·참여기관, 지도 3D 직접 클릭으로 시연 열기, 초기화/Escape/닫기/mini viewer 반환, 모션 감소 및 기존 음성 투어를 확인했다. 32개 캡처, 8개 axe 조합 위반 0, pageerror 0. 추가 터치 에뮬레이션으로 1080×1920와 3840×2160에서 구성 보기와 FA-50→MUAV 관계 이동·닫기를 확인하고 2개 캡처를 저장했다. 실제 키오스크 하드웨어 검증은 아니다.

객체 데이터 검사는 46개 고유 객체·53개 관계의 모든 연결 대상과 source ID가 존재함을 확인했다. 공통 기업의 공개 근거 연결과 공통 환경의 설명용 분류를 구분한다. 실제 체계 상호운용·공동 임무·OWL 추론 또는 제조사 CAD/성능 검증을 주장하지 않는다. 최종 독립 시각/기능 검토 PASS는 final-visual-review.md와 final-integrity-review.md에 있다. 세로·4K 화면에서 외형 조각이 잘리는 문제를 발견해 모형 경계와 가로/세로 시야각을 기준으로 카메라를 자동 맞추고, 역할 이동 범위의 여유 공간도 확보했다. 수정 후 34개 새 시연 캡처를 재검토했다. 현재 빌드와 소스 해시는 build-verification.json에 보관했다.

기존 홈·다섯 모드·레이아웃 34개 캡처/14개 axe, 기존 음성·지역·상세 22개 캡처/8개 axe 회귀 검사도 현재 v4 빌드에서 통과했다. regression-report.json과 exhibition-regression-report.json이 v4 회귀 기록이다. 기존 러너가 exhibition-v3 경로에 캡처를 갱신하므로 해당 폴더의 옛 v3 build-verification/검토는 당시 기록이며 갱신된 회귀 캡처의 현재 빌드 증명으로 사용하지 않는다. v4 Lighthouse 재측정은 수행하지 않았다. Three.js 공유 청크는 약 536KB로 빌드 경고가 남으며 선택 후 지연 로드한다.

## 지형·운용 환경 v6 검증

현재 버전은 10개 체계, 외부 3D 2개·실제 사진 3개·외형 확보 대기 5개다. 공개 DEM 33,971개 표본으로 지형을 구성했다. 지상 산악/평지, 수면, 수중, 공중, 연안, 우주 설명 환경을 구분한다. 움직이는 객체는 설명용 위치 표시이며 실제 장비 GLB/CAD와 지형의 통합은 미완료다.

최종 빌드 및 실제 Chrome 환경 30조합, 환경 캡처 47개, 외형 캡처 30개, 모바일 출처·연계 체계 스크롤 캡처 20개를 확인했다. 환경 모달 axe 위반 0, 브라우저 오류 0. 4K·세로 터치는 에뮬레이션이며 실제 키오스크 인증은 아니다. 지연 로딩 중 닫기/중지 취소, 모션 감소, 지형 삼각형과 표시 구체 간 간격을 별도 확인했다. 근거는 docs/evidence/environment-v6 아래 report.json, extra-controls.json, mesh-clearance.json, integrity-sphere-clearance-fixed.json, assets/report.json, deep-scroll/report.json 및 최종 독립 검토다. 기존 v3/v4 내용은 당시 버전의 역사적 기록이다.
