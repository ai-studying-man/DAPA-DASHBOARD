# 21종 외형 MVP · 제작·사용 근거

사용자가 제공한 21종 목록의 순서를 유지했습니다. K2·K9는 기존 사진 비교 보정 모델을 재사용했습니다. 원래 사진과 모델의 출처·조건은 ../k2-photo-refined-ATTRIBUTION.md 및 ../k9-photo-refined-ATTRIBUTION.md를 확인하세요.

나머지 19종은 본 프로젝트에서 Blender로 만든 장비 종류별 외형 초안입니다. AI 기준 이미지를 사진측량으로 복원한 모델이 아닙니다. AI 이미지와 외형의 세부 일치, 실제 치수·도색·부품 구조는 검증하지 않았습니다. 제조사 CAD나 완성된 실사 모델로 표시하지 않습니다. 새로 제작한 초안의 외부 재배포 조건은 프로젝트 소유자가 정해야 합니다.

기준 이미지 20종은 AI 생성 참고 자료이며 실제 촬영 사진이나 검증 도면이 아닙니다. KM187은 이미지 생성 도구에서 차단되어 기준 이미지가 없습니다. 이를 우회해 대체 이미지를 생성하지 않았습니다. KM187의 일반적인 외부 모형 MVP만 제공하며 정밀 형상과 제원을 의미하지 않습니다.

F-22·F-117은 대한민국 개발 체계가 아닌 해외 비교용 항목입니다. K10 화생방제독차와 K332 표기의 정확한 장비 정체·형상, K151 현궁 형상은 추가 확인이 필요합니다. K10 탄약운반장갑차와 동일 장비로 취급하지 않습니다.
