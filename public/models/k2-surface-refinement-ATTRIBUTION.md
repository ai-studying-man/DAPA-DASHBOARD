# K2 surface-role refinement candidate

This is an original exhibition reconstruction refined from this project's existing K2 exterior. The single inspected photograph is KBS VIEW–theDEEP / CC BY 3.0: https://commons.wikimedia.org/wiki/File:K2_Black_Panther_20161106.jpg . Camouflage netting obscures significant hull, turret and wheel surfaces. The photograph is a visual reference, not a texture scan or measured multi-view reconstruction.

The repeat camouflage texture is authored procedural artwork, not an actual K2 paint-pattern scan. Blender changes include duplicate triangle welding, exterior bevels, distinct paint/rubber/steel/recess/glass materials and 96 raised roadwheel rim fasteners. Bolt arrangement and bevel dimensions are illustrative rather than manufacturer-verified. No motion/physics is included. No Threads asset was reused.
